## 1. 性能监控系统概述

### 1.1 监控系统组件和功能

放射化学纯度检测仪的性能监控系统是一个全面的实时监控解决方案，包含以下核心组件：

**数据收集器 (Data Collector)**
- 实时收集系统性能指标
- API调用统计和响应时间监测
- 数据库查询性能分析
- 缓存命中率统计
- 系统资源使用情况监控

**监控服务 (Monitoring Service)**
- 后台运行的数据聚合服务
- 性能指标计算和存储
- 告警规则引擎
- 实时数据推送

**可视化界面 (Dashboard)**
- 实时性能监控面板
- 交互式图表和指标展示
- 历史数据查询和分析
- 自定义监控面板

### 1.2 监控范围和指标

监控系统覆盖以下关键领域：

**系统级指标**
- CPU使用率和负载
- 内存使用情况
- 磁盘I/O和空间
- 网络流量和连接状态

**应用级指标**
- API响应时间和吞吐量
- 数据库查询性能
- 缓存效率和命中率
- 用户会话和并发连接

**业务级指标**
- 检测任务执行时间
- 数据处理吞吐量
- 用户操作响应速度
- 系统可用性

### 1.3 实时监控和历史数据

**实时监控**
- 5秒间隔的数据刷新
- 实时告警和异常检测
- 即时性能指标查看
- 动态阈值调整

**历史数据存储**
- 短期数据（24小时）：1分钟精度
- 中期数据（7天）：5分钟精度
- 长期数据（30天）：1小时精度

## 2. 系统性能监控

### 2.1 CPU使用率监控

**监控指标**
- CPU整体使用率
- 各核心使用率分布
- 系统负载平均值（1分钟、5分钟、15分钟）
- CPU上下文切换频率

**正常值范围**
- CPU使用率：20% - 70%
- 系统负载：< 核心数 × 0.8
- 上下文切换：< 1000次/秒

**告警阈值**
- 警告：CPU使用率 > 80%（持续5分钟）
- 严重：CPU使用率 > 90%（持续2分钟）
- 紧急：CPU使用率 > 95%（持续1分钟）

**查看方法**
1. 打开性能监控面板
2. 选择"系统监控"选项卡
3. 查看CPU使用率图表
4. 点击具体时间点查看详细信息

### 2.2 内存使用监控

**监控指标**
- 物理内存使用率和剩余量
- 虚拟内存使用情况
- 内存碎片率
- 垃圾回收频率和耗时

**正常值范围**
- 内存使用率：30% - 80%
- 可用内存：> 1GB
- 内存碎片率：< 15%

**告警阈值**
- 警告：内存使用率 > 85%
- 严重：内存使用率 > 90%
- 紧急：可用内存 < 512MB

**优化建议**
- 定期重启清理内存碎片
- 优化内存泄漏的应用
- 调整JVM堆内存大小
- 启用内存压缩功能

### 2.3 磁盘空间监控

**监控指标**
- 各分区使用率
- 磁盘I/O吞吐量
- 磁盘读写响应时间
- 磁盘队列长度

**正常值范围**
- 磁盘使用率：< 85%
- I/O吞吐量：< 80% 最大值
- 读写延迟：< 10ms

**告警阈值**
- 警告：磁盘使用率 > 85%
- 严重：磁盘使用率 > 90%
- 紧急：磁盘使用率 > 95%

**清理策略**
- 定期清理日志文件
- 压缩历史数据
- 移动大文件到外部存储
- 启用磁盘配额管理

### 2.4 网络流量监控

**监控指标**
- 网络带宽使用率
- 网络连接数
- 网络延迟和丢包率
- 网络错误统计

**正常值范围**
- 带宽使用率：< 70%
- 并发连接数：< 1000
- 网络延迟：< 100ms
- 丢包率：< 0.1%

**告警阈值**
- 警告：带宽使用率 > 80%
- 严重：网络延迟 > 500ms
- 紧急：连接数 > 90% 最大值

### 2.5 系统负载监控

**负载指标**
- 1分钟、5分钟、15分钟平均负载
- 负载趋势分析
- 峰值负载统计
- 负载与CPU使用率关联分析

**负载分析**
- 负载 < 核心数：系统正常运行
- 负载 = 核心数：系统满载
- 负载 > 核心数：系统过载

## 4. 数据库性能监控

### 4.1 查询性能统计

**查询指标**
- 查询执行时间分布
- 慢查询数量和比例
- 查询复杂度分析
- 查询频率统计

**性能统计示例**
```sql
-- 慢查询统计
SELECT 
    query,
    count(*) as execution_count,
    avg(execution_time) as avg_time,
    max(execution_time) as max_time,
    min(execution_time) as min_time
FROM performance_metrics 
WHERE metric_type = 'database_query'
AND execution_time > 100
GROUP BY query
ORDER BY avg_time DESC;
```

**查询性能基线**
- 简单查询：< 50ms
- 复杂查询：< 200ms
- 报表查询：< 2s
- 批量操作：< 10s

- 按缓存键分组命中率
- 时间段命中率变化
- 缓存失效原因统计

**命中率计算**
```
命中率 = 缓存命中次数 / (缓存命中次数 + 缓存未命中次数) × 100%
```

- 静态数据缓存：> 95%

### 11.3 API调用示例

**完整监控数据获取**
```javascript
// 获取完整监控数据
class MonitoringClient {
  constructor(baseURL, token) {
    this.baseURL = baseURL;
    this.token = token;
  }

  async getSystemMetrics() {
    const response = await fetch(`${this.baseURL}/system`, {
      headers: {
        'Authorization': `Bearer ${this.token}`,
        'Content-Type': 'application/json'
      }
    });
    return response.json();
  }

  async getAPIMetrics(params = {}) {
    const query = new URLSearchParams(params);
    const response = await fetch(`${this.baseURL}/api?${query}`, {
      headers: {
        'Authorization': `Bearer ${this.token}`,
        'Content-Type': 'application/json'
      }
    });
    return response.json();
  }

  async getDatabaseMetrics() {
    const response = await fetch(`${this.baseURL}/database`, {
      headers: {
        'Authorization': `Bearer ${this.token}`,
        'Content-Type': 'application/json'
      }
    });
    return response.json();
  }

  async getCacheMetrics() {
    const response = await fetch(`${this.baseURL}/cache`, {
      headers: {
        'Authorization': `Bearer ${this.token}`,
        'Content-Type': 'application/json'
      }
    });
    return response.json();
  }
}

// 使用示例
const client = new MonitoringClient('http://localhost:3000/api/monitoring', 'your-token');

// 获取所有监控数据
async function getAllMetrics() {
  try {
    const [system, api, database, cache] = await Promise.all([
      client.getSystemMetrics(),
      client.getAPIMetrics({ period: '1h' }),
      client.getDatabaseMetrics(),
      client.getCacheMetrics()
    ]);

    return {
      system,
      api,
      database,
      cache,
      timestamp: new Date().toISOString()
    };
  } catch (error) {
    console.error('获取监控数据失败:', error);
    throw error;
  }
}
```

## 监控指标说明

### 性能指标含义

**系统指标**
- CPU使用率：处理器时间占用百分比
- 内存使用率：物理内存占用百分比  
- 磁盘使用率：存储空间占用百分比
- 网络带宽使用率：网络传输能力占用百分比

**应用指标**
- API响应时间：请求到响应的时间间隔
- API错误率：失败请求占总请求的百分比
- 数据库查询时间：SQL语句执行耗时
- 缓存命中率：缓存命中占总查询的百分比

### 正常值范围

| 指标类型 | 警告阈值 | 严重阈值 | 紧急阈值 |
|---------|---------|---------|---------|
| CPU使用率 | > 80% | > 90% | > 95% |
| 内存使用率 | > 85% | > 90% | > 95% |
| 磁盘使用率 | > 85% | > 90% | > 95% |
| API响应时间(P95) | > 500ms | > 1000ms | > 2000ms |
| API错误率 | > 1% | > 5% | > 10% |
| 缓存命中率 | < 70% | < 50% | < 30% |
| 数据库连接使用率 | > 80% | > 90% | > 95% |

### 指标计算方法

**响应时间计算**
```
平均响应时间 = Σ(响应时间) / 请求总数
P95响应时间 = 第95百分位数响应时间
P99响应时间 = 第99百分位数响应时间
```

**错误率计算**
```
错误率 = 错误请求数 / 总请求数 × 100%
成功率 = 成功请求数 / 总请求数 × 100%
```

**缓存命中率计算**
```
命中率 = 缓存命中次数 / (缓存命中次数 + 缓存未命中次数) × 100%
```

### 指标关联关系

**CPU与响应时间**
- CPU使用率升高通常导致响应时间增加
- 响应时间增长可能表明CPU成为瓶颈

**内存与数据库性能**
- 内存不足会导致数据库查询变慢
- 数据库缓存命中率影响整体性能

**网络与API性能**
- 网络延迟直接影响API响应时间
- 带宽不足影响大量数据传输
