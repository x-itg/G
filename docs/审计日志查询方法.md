## 1. 审计日志系统概述

### 1.1 审计日志的作用和重要性

审计日志是放射化学纯度检测仪系统的核心安全组件，用于：

- **追踪用户操作**: 记录所有用户登录、登出、权限变更等操作
- **监控数据变更**: 跟踪所有关键数据的创建、修改、删除操作
- **保障数据完整性**: 确保操作记录的完整性和可追溯性
- **支持合规审计**: 满足FDA CFR 21 Part 11电子记录要求
- **安全事件调查**: 提供详细的安全事件调查依据

### 1.2 CFR 21 Part 11合规性要求

系统严格遵循CFR 21 Part 11电子记录和电子签名规定：

#### 合规要求
- **完整性**: 所有操作必须完整记录，不得缺失
- **可追溯性**: 每个记录必须能够追溯到具体用户和时间
- **不可篡改性**: 审计日志记录不能被修改或删除
- **时间戳**: 所有记录必须包含准确的UTC时间戳
- **电子签名**: 关键操作需要电子签名确认

#### 合规特性
```
- 审计日志防篡改机制
- 数字签名验证
- 完整性校验
- 时间戳验证
- 用户身份确认
- 操作记录完整保存
```

### 1.3 日志记录范围和内容

#### 记录范围
- **用户管理**: 登录、登出、权限变更、密码修改
- **系统操作**: 设备连接、配置变更、数据导出
- **检测操作**: 样品检测、结果确认、数据修改
- **电子签名**: 签名创建、验证、撤销
- **安全事件**: 异常登录、权限冲突、系统错误

#### 基本字段
```json
{
  "timestamp": "2025-12-06T17:28:19.000Z",
  "userId": "user_001",
  "username": "admin",
  "action": "LOGIN",
  "resource": "/api/auth/login",
  "result": "SUCCESS",
  "ipAddress": "192.168.1.100",
  "userAgent": "Mozilla/5.0...",
  "details": {...}
}
```

### 1.4 日志完整性和不可篡改性

#### 完整性保障
- **哈希链式结构**: 每条日志记录包含前一条记录的哈希值
- **数字签名**: 使用RSA-2048算法对关键日志进行数字签名
- **时间戳服务**: 集成NIST时间戳服务确保时间准确性
- **备份验证**: 多重备份和完整性验证机制

#### 防篡改机制
```javascript
// 日志记录完整性检查
function verifyLogIntegrity(logEntry, previousHash) {
    const calculatedHash = crypto
        .createHash('sha256')
        .update(JSON.stringify(logEntry) + previousHash)
        .digest('hex');
    
    return logEntry.hash === calculatedHash;
}
```

## 3. 日志查询方法

### 3.1 基本查询语法和参数

#### 基础查询API
```http
GET /api/audit/logs
```

#### 基础参数
- `limit`: 返回记录数量限制 (默认: 100, 最大: 1000)
- `offset`: 偏移量 (默认: 0)
- `sort`: 排序字段 (默认: timestamp)
- `order`: 排序方向 (ASC/DESC, 默认: DESC)

#### 示例查询
```javascript
// 基础查询 - 获取最近100条记录
const logs = await fetch('/api/audit/logs?limit=100');

// 分页查询
const logs = await fetch('/api/audit/logs?limit=50&offset=50');

// 排序查询
const logs = await fetch('/api/audit/logs?sort=timestamp&order=ASC');
```

### 3.2 时间范围查询

#### 时间参数
- `startTime`: 开始时间 (ISO 8601格式)
- `endTime`: 结束时间 (ISO 8601格式)
- `dateFrom`: 日期开始 (YYYY-MM-DD)
- `dateTo`: 日期结束 (YYYY-MM-DD)

#### 时间范围查询示例
```javascript
// 按绝对时间范围查询
const logs = await fetch('/api/audit/logs?startTime=2025-12-01T00:00:00.000Z&endTime=2025-12-06T23:59:59.999Z');

// 按日期范围查询
const logs = await fetch('/api/audit/logs?dateFrom=2025-12-01&dateTo=2025-12-06');

// 相对时间查询 (最近24小时)
const logs = await fetch('/api/audit/logs?hoursAgo=24');

// 复合时间查询
const logs = await fetch('/api/audit/logs?startTime=2025-12-06T00:00:00.000Z&endTime=2025-12-06T23:59:59.999Z&limit=500');
```

#### 时间格式说明
```javascript
// 支持的时间格式
const timeFormats = {
    iso8601: "2025-12-06T17:28:19.000Z",
    date: "2025-12-06",
    datetime: "2025-12-06 17:28:19",
    timestamp: 1765012099000
};
```

### 3.3 用户筛选查询

#### 用户参数
- `userId`: 特定用户ID
- `username`: 用户名
- `role`: 用户角色
- `department`: 部门

#### 用户查询示例
```javascript

// 按用户名查询

```

### 3.4 操作类型筛选

#### 操作类型参数
- `action`: 特定操作类型
- `type`: 日志类型
- `resource`: 操作资源
- `category`: 操作分类

#### 操作类型查询示例
```javascript
// 按操作类型查询
const logs = await fetch('/api/audit/logs?action=LOGIN');

// 按日志类型查询
const logs = await fetch('/api/audit/logs?type=USER_ACTION');

// 按操作资源查询
const logs = await fetch('/api/audit/logs?resource=/api/auth/*');

// 按操作分类查询
const logs = await fetch('/api/audit/logs?category=authentication');

// 复合操作查询
const logs = await fetch('/api/audit/logs?action=LOGIN&type=USER_ACTION&result=SUCCESS');
```

### 3.5 关键词搜索功能

#### 搜索参数
- `search`: 关键词搜索
- `searchFields`: 搜索字段 (逗号分隔)
- `searchType`: 搜索类型 (exact/pattern/regex)

#### 关键词搜索示例
```javascript
// 基本关键词搜索
const logs = await fetch('/api/audit/logs?search=登录成功');

// 指定字段搜索
const logs = await fetch('/api/audit/logs?search=admin&searchFields=username,details.message');

// 正则表达式搜索
const logs = await fetch('/api/audit/logs?searchType=regex&search=ERROR.*timeout');

// 模式匹配搜索
const logs = await fetch('/api/audit/logs?searchType=pattern&search=*登录*');

// 复合搜索
const logs = await fetch('/api/audit/logs?search=认证&searchFields=action,details&searchType=pattern');
```

### 3.6 高级查询和组合条件

#### 高级参数
- `filter`: JSON格式的复杂过滤条件
- `groupBy`: 分组字段
- `aggregate`: 聚合函数
- `having`: 分组后条件

#### 复杂查询示例
```javascript
// JSON过滤条件
const filter = {
    "timestamp": {"$gte": "2025-12-01T00:00:00.000Z"},
    "result": "SUCCESS",
    "action": {"$in": ["LOGIN", "LOGOUT"]}
};

const logs = await fetch(`/api/audit/logs?filter=${encodeURIComponent(JSON.stringify(filter))}`);

// 聚合查询
const logs = await fetch('/api/audit/logs?groupBy=action&aggregate=count&having=count>10');

// 复合查询
const query = '/api/audit/logs?' +
    'startTime=2025-12-01T00:00:00.000Z&' +
    'endTime=2025-12-06T23:59:59.999Z&' +
    'userId=user_001&' +
    'action=LOGIN&' +
    'result=SUCCESS&' +
    'limit=100&' +
    'sort=timestamp&order=DESC';

const logs = await fetch(query);
```

```javascript
class RealtimeMonitor {
    constructor() {
        this.socket = null;
        this.isConnected = false;
        this.filters = {};
        this.init();
    }

    init() {
        this.connectWebSocket();
        this.bindEvents();
    }

    connectWebSocket() {
        this.socket = new WebSocket('ws://localhost:8080/api/audit/stream');
        
        this.socket.onopen = () => {
            this.isConnected = true;
            this.subscribeToLogs();
        };

        this.socket.onmessage = (event) => {
            const logEntry = JSON.parse(event.data);
            this.addLogEntry(logEntry);
        };

        this.socket.onclose = () => {
            this.isConnected = false;
            setTimeout(() => this.connectWebSocket(), 5000);
        };
    }

    subscribeToLogs() {
        const subscription = {
            action: 'subscribe',
            filters: this.filters,
            types: ['USER_ACTION', 'SYSTEM_ERROR']
        };
        this.socket.send(JSON.stringify(subscription));
    }

    addLogEntry(log) {
        const table = document.getElementById('realtimeLogs');

        row.className = 'log-entry';
        row.innerHTML = `

            <td>${log.username}</td>
            <td>${log.action}</td>
            <td class="${log.result.toLowerCase()}">${log.result}</td>
            <td>${log.details}</td>
        `;
        
        table.insertBefore(row, table.firstChild);
        
        // 限制显示条数
        if (table.children.length > 100) {

        }
```

```javascript
// 数据完整性验证工具
class DataIntegrityChecker {
    async validateAuditLogs(startDate, endDate) {
        const validationReport = {
            total_records: 0,
            valid_records: 0,
            invalid_records: 0,
            issues: []
        };

        const result = await this.queryAllLogs(startDate, endDate);
        
        for (const log of result.logs) {
            validationReport.total_records++;
            
            // 检查必填字段
            if (!this.validateRequiredFields(log)) {
                validationReport.invalid_records++;
                validationReport.issues.push({
                    type: 'missing_required_field',
                    logId: log.id,
                    missingFields: this.getMissingFields(log)
                });
            }

            // 检查数据格式
            if (!this.validateDataFormat(log)) {
                validationReport.invalid_records++;
                validationReport.issues.push({
                    type: 'invalid_data_format',
                    logId: log.id,
                    issue: 'Data format validation failed'
                });
            }

            // 检查时间戳有效性
            if (!this.validateTimestamp(log.timestamp)) {
                validationReport.invalid_records++;
                validationReport.issues.push({
                    type: 'invalid_timestamp',
                    logId: log.id,
                    timestamp: log.timestamp
                });
            }

            // 检查哈希完整性
            if (!this.validateHashIntegrity(log)) {
                validationReport.invalid_records++;
                validationReport.issues.push({
                    type: 'hash_mismatch',
                    logId: log.id,
                    expectedHash: log.expected_hash,
                    actualHash: log.calculated_hash
                });
            }

            if (validationReport.invalid_records === 0) {
                validationReport.valid_records++;
            }
        }

        return validationReport;
    }

    validateRequiredFields(log) {
        const requiredFields = [
            'id', 'timestamp', 'type', 'action', 
            'userId', 'result'
        ];
        return requiredFields.every(field => log[field] != null);
    }

    validateDataFormat(log) {
        // 验证IP地址格式
        if (log.ipAddress && !this.isValidIP(log.ipAddress)) {
            return false;
        }

        // 验证时间戳格式
        if (log.timestamp && !this.isValidTimestamp(log.timestamp)) {
            return false;
        }

        return true;
    }

    isValidIP(ip) {
        const ipRegex = /^(?:(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.){3}(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)$/;
        return ipRegex.test(ip);
    }

    isValidTimestamp(timestamp) {
        const date = new Date(timestamp);
        return date instanceof Date && !isNaN(date);
```

#### 结果验证工具
```javascript
// 查询结果验证工具
class QueryResultValidator {
    validateQueryResults(result, expectedResult) {
        const validation = {
            isValid: true,
            errors: [],
            warnings: []
        };

        // 验证基本结构
        if (!this.validateBasicStructure(result)) {
            validation.isValid = false;
            validation.errors.push('Result structure is invalid');
        }

        // 验证数据完整性
        if (!this.validateDataCompleteness(result, expectedResult)) {
            validation.warnings.push('Data completeness issues detected');
        }

        // 验证排序正确性
        if (!this.validateSorting(result)) {
            validation.errors.push('Sorting order is incorrect');
        }

        // 验证分页正确性
        if (!this.validatePagination(result)) {
            validation.errors.push('Pagination is incorrect');
        }

        return validation;
    }

    validateBasicStructure(result) {
        return result && 
               result.status === 'success' && 
               result.data && 
               Array.isArray(result.data.logs);
    }

    validateDataCompleteness(result, expected) {
        if (!expected) return true;
        
        const actualCount = result.data.logs.length;
        const expectedCount = expected.total || actualCount;
        
        return Math.abs(actualCount - expectedCount) <= expectedCount * 0.1;
    }

    validateSorting(result) {
        const logs = result.data.logs;
        if (logs.length <= 1) return true;

        // 检查排序是否正确
        for (let i = 1; i < logs.length; i++) {
            if (logs[i-1].timestamp < logs[i].timestamp) {
                return false; // 时间戳应该是降序排列
            }
        }
        return true;
    }

    validatePagination(result) {
        const pagination = result.data.pagination;
        if (!pagination) return true;

        return pagination.limit > 0 && 
               pagination.offset >= 0 && 
               pagination.total >= 0;
    }
}
```

```javascript
// 导出监控和诊断工具
class ExportMonitor {
    async monitorExport(exportId) {
        const status = await this.getExportStatus(exportId);
        
        const monitoring = {
            status: status,
            progress: 0,
            estimatedTimeRemaining: 0,
            potentialIssues: [],
            recommendations: []
        };

        // 分析导出状态
        if (status.status === 'processing') {
            monitoring.progress = status.progress;
            monitoring.estimatedTimeRemaining = this.estimateRemainingTime(status);
            
            // 检查潜在问题
            if (status.progress === 0 && Date.now() - status.startTime > 30000) {
                monitoring.potentialIssues.push('Export appears to be stuck');
                monitoring.recommendations.push('Consider canceling and retrying with smaller dataset');
            }
            
            if (status.memoryUsage > 0.8) {
                monitoring.potentialIssues.push('High memory usage detected');
                monitoring.recommendations.push('Consider reducing batch size');
            }
        }

        return monitoring;
    }

    async diagnoseExportProblems(exportId) {
        const diagnosis = {
            exportId: exportId,
            issues: [],
            solutions: [],
            prevention: []
        };

        const status = await this.getExportStatus(exportId);
        const metrics = await this.getExportMetrics(exportId);

        // 问题诊断逻辑
        if (status.error) {
            diagnosis.issues.push({
                type: 'execution_error',
                message: status.error,
                severity: 'high'
            });
            
            if (status.error.includes('memory')) {
                diagnosis.solutions.push('Increase memory limit or reduce batch size');
                diagnosis.prevention.push('Use smaller time ranges for exports');
            }
            
            if (status.error.includes('timeout')) {
                diagnosis.solutions.push('Increase timeout limits');
                diagnosis.prevention.push('Use async export mode for large datasets');
            }
        }

        if (metrics.recordsPerSecond < 100) {
            diagnosis.issues.push({
                type: 'performance',
                message: 'Export is running slower than expected',
                severity: 'medium'
            });
            diagnosis.solutions.push('Check database performance and indexing');
        }

        return diagnosis;
    }

    estimateRemainingTime(status) {
        if (status.progress === 0) return null;
        
        const elapsed = Date.now() - status.startTime;
        const rate = status.progress / elapsed;
        const remaining = (100 - status.progress) / rate;
        
        return Math.round(remaining / 1000); // 返回秒数
    }
}
```
