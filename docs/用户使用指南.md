## 快速入门

### 系统安装和配置

#### 环境要求
- **操作系统**: Windows 10/11, Linux (Ubuntu 20.04+), macOS 12+
- **内存**: 最低8GB，推荐16GB以上
- **存储**: 最低50GB可用空间
- **网络**: 稳定的互联网连接（首次安装需要）

#### 安装步骤

1. **下载安装包**
   - 从官方网站下载最新版本安装包
   - 验证安装包完整性（MD5校验）

2. **运行安装程序**
   ```
   ./setup.exe  # Windows
   sudo ./setup.sh  # Linux
   ```

3. **数据库配置**
   - 输入PostgreSQL数据库连接信息
   - 配置Redis缓存服务器地址
   - 设置数据库用户权限

4. **系统初始化**
   - 等待数据库表结构创建完成
   - 初始化默认配置参数
   - 创建系统管理员账号

### 首次使用设置

#### 1. 系统配置向导
启动系统后，首次登录将进入配置向导：

**安全策略配置**

验证步骤：

## 新增功能指南

### 权限管理系统使用

#### 三级权限体系结构

**操作员权限 (Level 1)**
- 执行日常检测操作
- 录入样品和检测数据
- 查看自己的检测记录
- 修改未提交的数据

**主管权限 (Level 2)**
- 包含操作员所有权限
- 审核和批准检测结果
- 执行电子签名确认
- 查看部门内所有记录

**管理员权限 (Level 3)**
- 包含前两级所有权限
- 系统配置和维护
- 用户账号管理
- 数据备份和恢复

#### 权限分配操作

1. **创建用户账号**
   - 点击"系统管理" → "用户管理"
   - 填写用户基本信息
   - 选择权限级别
   - 设置账号状态

2. **修改用户权限**
   - 选中目标用户
   - 点击"编辑权限"
   - 调整权限级别
   - 确认修改操作

3. **权限继承规则**
   ```
   权限继承关系：
   管理员 (100%) > 主管 (70%) > 操作员 (40%)
   ```

#### 权限验证机制
**实时权限检查**
- 每次操作前验证权限
- 动态权限调整
- 权限变更即时生效

**操作日志记录**
- 记录所有权限相关操作
- 权限变更历史追踪
- 异常权限访问告警

### 电子签名操作流程

#### 电子签名类型

**审批签名**
- 检测结果最终确认
- 报告发布批准
- 重要参数修改授权

**操作签名**
- 数据录入完成确认
- 关键步骤执行确认
- 异常情况处理确认

#### 签名操作步骤

1. **签名准备**
   - 选择需要签名的内容
   - 确认签名意图和范围
   - 系统验证当前用户权限

2. **身份验证**
   ```
   验证方式：
   1. 用户名+密码验证
   2. 双因素认证（可选）
   3. 生物特征识别（可选）
   ```

3. **签名执行**
   - 查看签名内容摘要
   - 确认签名理由
   - 提交电子签名

4. **签名验证**
   - 系统生成唯一签名ID
   - 记录签名时间戳
   - 保存签名证书

#### 签名证书管理

**证书生成**
- 基于RSA算法的数字证书
- 证书有效期管理
- 证书更新和续期

**证书验证**
- 签名完整性验证
- 证书有效性检查
