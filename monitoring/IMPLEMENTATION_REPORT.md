## 使用建议

### 基本使用
```javascript
const { DataCollector } = require('./monitoring/dataCollector');

const collector = new DataCollector({
    interval: 5000,
    validationEnabled: true,
    anomalyDetectionEnabled: true
});

await collector.start();
const status = collector.getCollectionStatus();
```

### API集成
```javascript
const { createDataCollectorAPI } = require('./monitoring/dataCollectorAPI');
app.use('/api/monitoring/collection', createDataCollectorAPI(collector));
```

### 测试运行
```bash
# 快速验证
node dataCollectorTest.js quick

# 功能演示
node demo.js
```
