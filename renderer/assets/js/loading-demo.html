🚀 加载状态指示系统演示

系统状态

检查加载指示器系统的当前状态和可用功能。

基本加载指示器

演示不同类型的加载指示器，包括简单加载、带消息加载和带进度加载。

操作特定加载器

演示右上角的操作特定加载器卡片，适用于特定操作的反馈。

包装的异步操作

演示如何包装现有的异步操作，自动显示和隐藏加载指示器。

高级功能

演示高级功能，包括操作取消、多加载器和性能监控。

模块集成演示

演示已集成加载指示器的各个模块的实际操作。

✨ 核心特性

  • 全局和操作特定加载器
  • 实时进度显示
  • 操作取消功能
  • 多种动画效果
  • 响应式设计

🎯 已集成模块

  • AnalysisModule (数据分析)
  • DeviceManager (设备管理)
  • FileManager (文件管理)
  • DataProcessing (数据处理)

🔧 API 方法

  • show() - 显示加载器
  • hide() - 隐藏加载器
  • updateProgress() - 更新进度
  • wrap() - 包装异步操作

⌨️ 快捷键

  • ESC - 取消所有操作
  • 键盘导航支持
  • 屏幕阅读器兼容
  • 焦点管理
