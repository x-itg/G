## 🚀 使用方法

### 基础使用
```javascript
// 显示简单加载
window.LoadingIndicator.showSimple();

// 显示带进度加载
const loaderId = window.LoadingIndicator.show({
    message: '正在处理...',
    showProgress: true,
    enableCancel: true
});
```

### 高级使用
```javascript
// 包装异步操作
const wrappedOperation = window.LoadingIndicator.wrap(async () => {
    await performLongOperation();
    return '完成';
}, { message: '执行操作', showProgress: true });

await wrappedOperation();
```

### 已集成的模块直接使用
```javascript
// 这些方法已经自动集成加载指示器
window.AnalysisModule.performAnalysis();
window.DeviceManager.connectDevice(deviceId);
window.FileManager.generateReport(analysisId);
window.DataProcessing.processManualData();
```
